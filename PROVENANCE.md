# Provenance

What on this site comes from where. The distinction matters because the site
teaches, and a learner should always be able to tell sourced material from
material written for the site.

## The study guide

All nine sections, the glossary, the seven formulas, the ten comparisons, the
fifteen confusion points, the code blocks and questions Q5–Q10 are transcribed
from a 5-page PDF exam study guide for an "Algorithmic Trading with Python"
course (`wkhtmltopdf`, created 2026-09-15). Anything derived from it is marked
`source: "guide"` in `src/content/`.

**The guide's question section begins at Q5.** Q1–Q4 are absent from the
document. Four replacements were written for this site and are marked
`source: "authored"`, which renders an "authored" badge in the UI. Two glossary
terms (mean reversion, drawdown) and one extra question on overfitting are
likewise authored.

### One place the site goes beyond the guide

The guide states that using `<` instead of `crossed_below` gives "more trades →
more fee drag → wrong answer". Measured across three regimes and 27 parameter
combinations, plain `<` fires **2–4× more signals** but produces the **same
number of trades in 25 of 27 cases**, because `from_signals` ignores an entry
while already long. The guide's causal chain is a simplification.

The site teaches the guide's rule as the answer to give — it is what the exam
marks — and shows both the signal count and the order count in the lab so the
learner can see where the damage does and does not land. See the comment on the
test in `src/data/data.test.ts`.

## The market data

**All bundled price data is synthetic.** It is generated by
`scripts/generate-series.mjs` from a seeded PRNG, so it is deterministic and
reproducible. Nothing in `src/data/*.json` is a real market price.

Why: Yahoo's chart API returns HTTP 429 from this machine on both `query1` and
`query2`, through four retries with exponential backoff. The one free CSV
alternative (Stooq) answers with a JavaScript proof-of-work bot check rather
than data, which was not circumvented. `scripts/fetch-prices.mjs` is retained
as the real-data path for whenever the network cooperates; it writes the same
file shapes.

Synthetic data also earns its place: three deliberately different regimes let a
learner watch the same strategy win and lose without changing a parameter,
which is the lesson of unit 2.3 and something a single real series could not
show.

- `src/data/series.json` — 3 regimes × 520 daily bars (choppy, trending, crash)
- `src/data/monthly.json` — 15 assets × 36 months

The monthly tickers are Z-prefixed NATO-alphabet names (`ZALFA`, `ZBRVO`, …) so
none collides with a real listed ticker. An earlier draft used plausible
four-letter names and two of them — `IONQ` and `NVTA` — turned out to be real
companies.

Every page that renders this data carries the `DATA_NOTICE` string from
`src/data/index.ts` on screen.

### Not reproduced

The guide's Tesla demo figures ($10,000 passive → $9,964; Bollinger strategy →
$14,869) are **not** reproduced anywhere on this site, and are presented only as
the guide's own claim. They depend on an exact symbol, date range, window and
data vintage that the guide does not state.
