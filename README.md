# Algorithmic Trading School

An interactive site for learning algorithmic trading with Python — Bollinger
Bands, portfolio optimization and backtesting — built from a five-page exam
study guide.

Three jobs, one content source:

- **Study guide** — the nine sections, navigable and searchable.
- **The software** — the `yfinance` / `skfolio` / `vectorbt` workflow made
  executable. Move the window slider and *watch* the bands widen.
- **Grading** — questions marked immediately, with worked explanations and a
  weak-spot list that remembers what you keep missing.

Everything computes in the browser. No install, no API keys, no account.

## Running it

```bash
npm install
npm run dev          # http://localhost:3100
```

Port 3100, because 3000 collides with the two barbershop sites.

| Script | What it does |
|---|---|
| `npm run dev` | Dev server on 3100 |
| `npm run build` | Static export into `out/` |
| `npm run preview` | Serve the built `out/` on 3210 |
| `npm test` | Vitest |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |
| `npm run check` | All four, in order. The gate. |

## Layout

```
src/lib/            the engine — pure, dependency-free, unit-tested
  stats.ts          mean, SD, pct_change, rolling windows (pandas semantics)
  metrics.ts        return, risk, Sharpe, bandwidth, window-in-bars
  bollinger.ts      band construction; crossings AND plain comparisons
  backtest.ts       from_signals, with a position state machine
  optimize.ts       long-only min-variance and max-Sharpe
  progress.ts       quiz results in localStorage
  clientStore.ts    useSyncExternalStore wrappers for theme and progress
src/content/        every fact from the guide, as typed data
src/data/           bundled price series (synthetic — see PROVENANCE.md)
src/app/            routes
scripts/            data generation and the real-data fetch path
```

## Data

The bundled price data is **synthetic and deterministic**, generated by
`scripts/generate-series.mjs`. Yahoo's API rate-limits this machine and the free
CSV alternative sits behind a bot check. Full reasoning, and the real-data path,
in [PROVENANCE.md](PROVENANCE.md).

```bash
node scripts/generate-series.mjs   # regenerate the synthetic series
node scripts/fetch-prices.mjs      # real data, when the network cooperates
```

## Tests

66 tests. The ones that matter most pin the engine to the study guide's own
printed answers — the Agilent return of −6.65%, the Sharpe ratio of 0.645, the
6.7σ bandwidth, the 15-bar window. If the site ever disagreed with its source,
the build would fail.

The rest assert properties: that `crossed_below` fires only on the transition
bar, that a backtest never sells before it has bought, that bands start at bar
`window`, and that each optimizer beats equal weighting at its own objective.

## Deploying

Builds to a static export in `out/`, so it will go anywhere. Nothing has been
deployed yet — the two candidate paths are a manual Amplify zip upload via the
`aws` CLI (the proven route on this machine) or GitHub Pages via
`NEXT_PUBLIC_BASE_PATH`. GitHub Pages needs `gh auth refresh -s workflow` first,
since the current token lacks the `workflow` scope.

Environment variables, matching the sibling projects:

- `NEXT_PUBLIC_SITE_URL` — drives canonicals, OG tags, sitemap and robots
- `PREVIEW_NOINDEX=1` — keeps a preview build out of search results
- `NEXT_PUBLIC_BASE_PATH` — for sub-path hosting

## Not investment advice

This is teaching material. The strategy it teaches loses money in plenty of
markets — the trending regime in the lab shows a strategy ending at $11,991
against $27,489 for simply buying and holding.
